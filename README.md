# TECHIN 510 - Week 7: Agentic OS

## Overview
Create an agentic OS to serve your purpose. The agentic OS should be different than the job application agentic OS demonstrated in class.

## Deliverables

Submit all artifacts of this project to Github classroom and merge to main branch.
Ensure all results are reproducible with clear instructions on how to start your project.
In README.md, answer:
1. What is the purpose of your agentic OS
2. How does this agentic OS address your need
3. Provide a list of skills enabled in your agentic OS and how some of the skills collaborate/chain for complicated tasks.
